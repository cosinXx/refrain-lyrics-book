# 歌词核对质量标准

歌词是歌词本的核心，**必须联网获取并逐字核对**，禁止凭模型记忆书写。本文件定义抓取、核对、修正的完整规则。

## 歌词来源优先级
1. `scripts/fetch_lyrics.py`（QQ音乐公开接口：搜索 `c.y.qq.com/soso/fcgi-bin/search_for_qq_cp` → 歌词 `c.y.qq.com/lyric/fcgi-bin/fcg_query_lyric_new.fcg?songmid=...`）。
2. `general_search` 搜「歌名 歌手 歌词」补齐 problem 歌曲。
3. 浏览器打开音乐平台歌词页提取（最后手段）。

## 抓取校验
- 每首必须检查返回的 `source_song` / `source_artist` 是否与目标一致——**同名歌多位歌手**场景（如《红豆》方大同/王菲、〈宠爱〉TFBOYS、〈最好的安排〉曲婉婷）极易抓错版本。
- 抓到的行数异常少（<10 行）或异常多（>200 行）要人工复查。

## 修正规则（核对时逐条执行）
1. **错别字**：与来源逐字比对，修正形近/音近错字（实例：曹操「谋」→「摸」、舞娘「掉落」→「抖落」、春泥「花语」→「话语」）。
2. **漏句/多句**：补回缺失的主歌/副歌，删去不属于本歌的句子。
3. **副歌重复**：歌词本用途是「无聊时唱歌打发时间」，重复副歌只保留第一遍（脚本自动去重），每遍词不同的保留。
4. **分唱标记**：删除单独成行的「源：/凯：/玺：/合：/男：/女：/rap：/bridge：/独白：/对白：」等。
5. **时间轴**：`[00:12.34]` 标记删除。
6. **外文歌词**：用户点名的是中文歌时，若抓到韩文/英文版（实例：菲梦少女《千千结》抓到韩文版），删除或换正确中文版本，并向用户说明。

## 超长歌处理
- 去重后仍 >68 行（A5 一栏 6pt 也放不下，脚本会警告）的歌，人工精简到核心段落：主歌1+副歌+主歌2（若词不同）+桥段，删除尾奏念白、纯重复铺垫。
- 实例：野狼disco（原 125 行）、为爱启程（原 80 行）精简到 50-55 行。
- 精简底线：保留用户会唱/爱唱的经典段落，宁可少不可错。

## 抽查与验收
- 用户重点点名的歌（如宠爱、冻结、刻在我心底的名字）逐字核对。
- 交付前随机抽 3-5 首重新联网比对一次。
- 所有修正结果写入 `status`：ok（无修改）/ fixed（已修正）/ problem（搜不到或争议），problem 必须向用户说明原因。
