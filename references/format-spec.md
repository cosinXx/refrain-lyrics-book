# A5 歌词本格式规范

本文件是 `build_lyrics_book.py` 输出格式的完整规格。修改脚本或手工排版时必须遵守。

## 页面
- 默认 A5：**148 × 210 mm**，页边距 10mm（可选 B5 176×250、A4 210×297）。
- 打印方式：双面。正文两栏，一页左右各一首歌。

## 文档结构
1. **标题页**（单栏）：书名居中（如「cosinX 的歌词乐理本」，22pt 黑体加粗）+ 副行「共 N 首 · MY LYRICS」（11pt 灰）。
2. **目录页**（单栏新页）：标题「目 录」+ 两列无边框表格（固定列宽，禁用 autofit），条目格式 `  N. 歌名  歌手`（序号 3 位右对齐固定宽度），7pt 黑体，行距 9pt。
3. **正文**（新节、两栏）：每首歌一组段落，组间用分栏符分隔。

## 一栏一首的核心实现
- 每首歌开头（除第一首）**先插入 column break**（`<w:br w:type="column"/>`），强制从新栏开始。
- 歌名/歌手/每行歌词段落全部设置：
  - `keep_together`（段内不拆页）
  - `keep_with_next`（与下段同页，末行歌词除外）
- 效果：一首歌无论长短都完整落在一栏内，绝不跨页、绝不串栏。

## 序号
- 正文每首歌标题前缀 `N. 歌名`，目录条目同序号，**严格一致**（从 1 到 N 连续）。
- 歌名段字号 = 正文字号 + 1.5pt（最小 7pt），黑体加粗。

## 字号自适应表（A5 一栏可用高度 538.6pt，实际核算值）
| 歌词行数 | 正文字号 | 行距 |
|---|---|---|
| ≤38 | 8.5pt | 11.5pt |
| 39-46 | 7.5pt | 10.0pt |
| 47-52 | 7.0pt | 9.5pt |
| 53-58 | 6.5pt | 8.5pt |
| 59-62 | 6.0pt | 7.5pt |
| >62 | **脚本自动精简**（删纯语气词行→截断加……），`--keep-full` 时仅警告 | — |

- 正文宋体（Songti SC，eastAsia=宋体），歌名黑体，歌手行比正文小 1.5pt 灰色。
- 副歌重复标记行（`（副歌 ×2）`）：灰色斜体，字号 = 正文 - 1.5pt（下限 6pt）。
- 校验规则：**任何行（含歌手行、副歌标记行）不得小于 6pt**；脚本对空歌词歌跳过并警告、对超长歌自动精简并在 stderr 报告被精简的歌曲清单。

## 歌词清洗规则（生成时自动执行）
1. 空行剔除。
2. 分唱标记行（`源：/凯：/玺：/合：/男：/女：/rap：/bridge：/独白：`等单独成行）删除。
3. **歌手集合重叠去重**：按归一化歌名分组，组内歌手集合有交集（或任一方为空）即视为同一首，保留歌词最多的版本；解决不同平台首歌手不同导致的漏去重。
4. 块级去重：normalize（去语气词/叹词/标点）后相同的连续 4-12 行块只留第一遍；被删重复块位置插入灰色斜体「（副歌 ×2）」标记（`--no-chorus-mark` 关闭）。
5. **超长歌自动精简**：>62 行时先删纯语气词/叹词行，仍超长则截断到前 61 行 + 「……」（`--keep-full` 关闭）。
6. 时间轴标记 `[00:12.34]` 在抓取时已剥离。
